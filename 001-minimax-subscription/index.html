1 一句话价值

在 WorkBuddy 里接入 MiniMax 订阅套餐后，对话 token 走套餐额度计费，不再按单次调用量付费，从而压缩 AI 工具的固定支出。

3 真实痛点证据

WorkBuddy 用量明细页（套餐与用量 → 用量明细）就是"按次计费"的最直接证据：每条请求一行，积分消耗看得清清楚楚。

WorkBuddy「用量明细」真实截图 · 每条对话都按积分消耗结算
看截图能发现：单次对话消耗 0~180 积分不等，模型不同消耗差异巨大；高频使用下月底账单完全不可预期。这就是 001 要解决的问题。

4 实现原理

MiniMax Token Plan 是独立于按量付费的订阅额度体系。在 WorkBuddy 中把 MiniMax 配置成自定义模型后，相关请求可走该订阅 Key 的额度池，把"按量计费"切换为"套餐内可用额度"。

5 准备条件

  • 已注册 MiniMax 平台账号并开通 Token Plan 订阅
  • WorkBuddy 设置权限，可进入模型管理页
  • 复制到 Token Plan 订阅 Key（sk-cp- 开头）

6 操作步骤

第 1 步
进入 WorkBuddy 模型管理页
打开 WorkBuddy 设置 → 模型 → 添加模型 → 选择"配置自定义模型"。
步骤 1 · WorkBuddy 添加模型入口
第 2 步
选择 Custom 提供商
在"添加模型"弹窗中，提供商选择"自定义 / Custom"；在"接口地址"中填入对应提供商的 OpenAI 兼容 API 地址。
步骤 2 · 选择 Custom 提供商并填写接口地址
第 3 步
获取 MiniMax Token Plan 订阅 Key
登录 MiniMax 控制台，进入订阅付费页面，复制 Token Plan 订阅 Key（sk-cp- 开头）。
步骤 3 · MiniMax 控制台订阅 Key 位置
第 4 步
填写模型信息并保存
回到 WorkBuddy 编辑模型页，填入 API Key、模型名称，按需勾选功能开关，保存。
步骤 4 · 填入 API Key 并保存

7 最终达成

WorkBuddy 中新增一条可用的 MiniMax 自定义模型配置，后续相关对话可走该订阅套餐额度计费，减少按量付费支出。
