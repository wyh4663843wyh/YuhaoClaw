009｜AI 出图 + PIL 填字中文封面合成工作流

AI 出底图 + PIL 填字，绕过中文乱码

一句话价值

用 AI 出干净的版面底图，再用 Python + PIL 把中文文字合成上去，解决 AI 模型中文乱码问题，产出可直接发布的中文封面。

解决的问题

直接让 AI 生成中文封面，会出现文字乱码、翻译成英文、跳过不写等问题。生成的图不能直接用，只能当底图再加工。

实现原理

把"出图"和"排字"拆成两步：AI 只负责版面、配色、氛围、装饰；中文文字由 PIL 用系统字体绘制。这样 AI 不用理解中文字，只需提供干净的版面。

准备条件

  • 安装 baoyu-image-gen skill（已就绪）
  • 配置 AI 生图 provider key（jimeng / MiniMax / 智谱任选其一）
  • 系统字体：`C:/Windows/Fonts/Noto Sans SC Bold (TrueType).otf`
  • Python 环境已装 Pillow

操作步骤

第一步：写版面 prompt

明确告诉 AI 出"无文字的版面"，例如：

  • 主标题位置（顶部居中）
  • 副标题位置（主标题下方）
  • 装饰元素位置（左上/右下角）
  • 配色和氛围

关键约束：

  • `NO TEXT, NO LETTERS, NO CHARACTERS, NO WATERMARKS`
  • `prompt_optimizer=false`（避免中文 prompt 被翻译）
  • `aspect_ratio: 3:4`（小红书常用竖版 864×1152）

第二步：调用 baoyu-image-gen 出底图

在 C:\Users\39705\.baoyu-skills\.env 配置 provider key 后：

baoyu-image-gen --prompt "版面描述" --provider jimeng --aspect-ratio 3:4

输出干净的版面 PNG，文字区域为空。

第三步：Python + PIL 合成中文

用 Pillow 在主标题和副标题位置绘制文字：

from PIL import Image, ImageDraw, ImageFont

img = Image.open("base.png")
draw = ImageDraw.Draw(img)

font_main = ImageFont.truetype(
    "C:/Windows/Fonts/Noto Sans SC Bold (TrueType).otf", 64)
font_sub = ImageFont.truetype(
    "C:/Windows/Fonts/NotoSansSC-VF.ttf", 32)

# 主标题居中
text = "研学 AI 工具流"
bbox = draw.textbbox((0, 0), text, font=font_main)
w = bbox[2] - bbox[0]
draw.text(((img.width - w) / 2, 120), text, font=font_main, fill="#2a2622")

# 副标题
sub = "讲解词 · 行程 · 物料 · 复盘"
bbox2 = draw.textbbox((0, 0), sub, font=font_sub)
w2 = bbox2[2] - bbox2[0]
draw.text(((img.width - w2) / 2, 220), sub, font=font_sub, fill="#5b514a")

img.save("final.png")

第四步：覆盖 AI 残留小字

如果底图上还有 AI 生成的小字（字母/装饰），用 Pillow 取周围像素色涂覆盖矩形：

# 取背景色
bg_color = img.getpixel((10, 10))
# 覆盖残留文字区域
draw.rectangle([(x1, y1), (x2, y2)], fill=bg_color)

第五步：添加印章/装饰

用纯色矩形 + 居中文字做装饰元素：

# 红色"研"印章
draw.rectangle([(50, 50), (130, 130)], fill="#a8302d")
draw.text((90, 90), "研", font=font_seal, fill="#fff")

最终达成

得到一张中文清晰、版面干净、可直接发布的小红书封面，无需后期再修改文字。
