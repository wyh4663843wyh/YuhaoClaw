1 一句话价值

同一个 prompt 同时发给多个模型，快速对比输出质量，选出最适合当前任务的结果，减少单模型试错成本。

2 解决的问题

不同模型擅长不同类型任务（创意 / 逻辑 / 代码 / 中文）；单模型跑出来的结果不满意，反复重试浪费时间。

3 实现原理

WorkBuddy 支持配置多个模型，同一个 prompt 可同时或先后发给不同模型，通过对比输出质量快速判断哪个模型更适合当前任务类型。

4 准备条件

  • WorkBuddy 中已配置多个可用模型
  • 明确当前任务类型（文案 / 方案 / 代码 / 翻译 / 数据分析）
  • 准备好统一的 prompt

5 操作步骤

第 1 步
明确任务类型
判断当前任务更偏向：创意发散 / 逻辑严谨 / 中文润色 / 代码生成 / 数据提取。
第 2 步
选择 2~3 个候选模型
根据任务类型挑选模型：中文文案选中文能力强的模型；逻辑推理选推理能力强的模型；代码生成选代码能力强的模型。
第 3 步
同一 prompt 分别发送
把相同 prompt 发给选中的 2~3 个模型，记录各自输出，不做任何预修改。
第 4 步
快速对比选优
判断标准：是否准确理解需求 / 输出结构是否清晰 / 是否有需要大改的内容 / 语气是否符合场景。
第 5 步
固化最优组合
把「任务类型 → 推荐模型」整理成个人速查表，下次直接调用。

6 对比示例（中文文案场景）

任务：小红书探店文案，150 字以内，需要有钩子和 CTA。

模型 A · 推理型
结构清晰，钩子标准
但语气偏正式
缺少小红书网感
✅ 适合：B 端 / 方案
模型 B · 中文型 ⭐
钩子自然
emoji 用得到位
CTA 直接可发
✅ 适合：本次任务
模型 C · 创意型
创意发散强
但结构松散
需要二次编辑
✅ 适合：标题 / slogan

结论：本次任务选 模型 B（中文型），直接可发。

7 选模型速查

任务类型推荐模型关键能力
中文文案 / 文旅方案中文能力强的模型语气润色、网感、CTA
逻辑推理 / 数据分析推理能力强的模型结构清晰、不跑偏
代码生成 / 脚本调试代码能力强的模型语法准、错误定位
创意发散 / 命名 / slogan创意强的模型联想广、不拘泥
数据提取 / 表格整理逻辑严谨的模型格式稳、不漏字段

8 最终达成

同一个任务不用反复重试同一个模型，通过对比快速找到最优解，整体出稿效率提升。
